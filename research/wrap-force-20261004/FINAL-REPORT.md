# G2 + Wuji 包覆承托与双向测力

完整连续仿真已做成，但最终真机与必要联合泛化目标尚未完成。默认 V12 使用原刀资产、G2 右臂与 Wuji，从桌角实际取刀、持稳，执行两轮 40 mm 伸出—保持—缩回—保持命令。名义条件及四个留出几何有实际功能通过记录。较高阻力仍失败，原刀总轴向推拉力尚未测到；本轮不运行真机，也不把交付完成写成目标完成。

默认原刀的实测拇指法向均值约 **0.747 N**，不是轴向推力。校准后的**修改串联装置**在两个独立包覆布局记录的有效运动中段得到约 **+0.200 / −0.202 N** 推／拉读数，已计入质量、世界加速度、重力、动基座及实际弹簧力。它改变了滑块动力学，不能称为原刀或实物推力；约 0.75 / 0.86 N 起动前瞬态不能称为可重复最大起动力。原刀 B 通道、导轨真实反力 C、实物阻力和 SDK 单位／接口仍是具体阻塞。

## 真实承托与抓姿比较

192缓存条目是四个原始来源各48扰动，没有扩成192种独立抓姿。先完成缓存到G2映射和四来源各自初始估计、闭合／取刀路径及双向参考适配，再用固定750、物理与负载筛选。部分持刀诊断可行而接回取刀失败，不能得出机械不可行结论，也没有要求任意抓姿成功。

选定包覆布局有原食指link4与远端指腹迁移、中指和小指指腹真实承托。与原source2同S120、同0.8模型压力档、原刀及匹配参考的持刀诊断对照，第二轮伸出 **21.71→33.42 mm**，新布局全功能通过。收益属于抓姿与必要控制适配共同作用，不能独立归因于包覆几何。原source2本来就有食指link4接触，不能宣称首次启用指节；掌面未证明有必要承托贡献。

实际碰撞几何与同步法向接触重建图、近景视频均给出。图只说明接触位置和力臂，求解器点数不等于真实面积，规划接触也不等于动态接触。将近端／掌面摩擦假设从0.8降至0.4、保持远端0.8和刀1.8，选定布局名义连续仍通过，0.35档仍失败；未知实物材料没有被称为已标定。

另一真正不同的正Z宽面拇指姿态，通过原资产全行程、闭合与G2取刀几何检查，实际形成中指link4持续承托。它的名义伸出可达约41–42 mm，带6 mm已知反向参考可缩至约1.61/0 mm，但跨轮转动仍失败。多接触平衡、取刀后中指参考和双向参考各有实际负结果，0.35/0.5档还暴露第二轮伸出不足与失联。未替换默认，也未围绕0.114与0.1 rad小数追加训练。
