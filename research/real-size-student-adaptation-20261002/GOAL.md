# Codex Goal：Wuji 实物尺寸刀的 student 持刀与开关适配（8×H200 / SSH）

请实际执行这一轮新 Goal，完成必要代码、短程训练、配对评测和 GitHub 交付，不只交计划，也不逐阶段等我确认。用户特别要求：避免过度安全、过度防御、重复审计和不会改变结论的工作；证据够用就交付。

## 1. 唯一研究目标和真实起点

当前实物近似刀的主体尺寸是135×16×12 mm（12 mm不含滑块凸起）。上一轮在**零新增滑动阻力、来源3**的8个开发初态上，teacher完成有序开关7/8、全程持刀稳定8/8；C3200 student完成有序开关3/8、全程稳定0/8，二者K20联合分别7/8、0/8。teacher和student的严格S5均为0/8。上一轮0.5/1.5 mm拇指位置偏置未稳定增加净法向接触力代理，独立确认各条件K20/S5均0/32；这只说明当时的student和位置偏置策略没成功，不能证明真实恒力按压无效。

因此本轮优先回答：**在teacher已有可用行为的这类抓姿和实物近似几何上，从当前C3200继续受控训练，能否让student学会持稳刀身并完成开关？** 不把增加导轨阻力、按压或S5精密到位作为启动训练的前置门槛。只有基础操作恢复后，才做少量阻力/按压迁移诊断。

## 3. 先做短基线，然后实际训练

从来源3、零新增阻力开始，沿用上轮修复后的静态抓姿规则。新生成独立的训练、开发和确认状态，按静态可行性固定顺序接受；不得挑选policy成功状态，不复用已经打开的上轮confirm。首个开发集16个新有效初态即可；保留实际接受率。与原资产的baseline保留项采用已有训练池和少量新评测状态，不重建巨型状态库。

必要预检仅限本次变化：
- 同一新资产、相同状态，teacher和C3200从reset的开关、持刀、失效时间；确认在至少一个抓姿子集中teacher仍表现明显好于student。
- teacher/student运行输入、bbox和source对应这把刀，按需修明确的坐标/抓姿错误；已有模块通过的恢复、跨设备对齐及发布审计不重做。
- 若teacher在照片修形后也无法形成多条稳定的完整开关轨迹，允许一次有依据的轻量接触/抓姿修正；修正后重新冻结配方。仍没有可用teacher轨迹时，停止以失败teacher标签蒸馏，交付具体失败和最小接触策略改动；不要盲目强训或全抓姿扫描。

只要teacher从reset有可用行为且student明显落后，就执行**一对等预算短训练**，不要再以旧2秒latent接管失败或“等所有精度指标先达标”为由延后。

两臂都从完全相同的C3200 encoder、optimizer/Adam状态、冻结actor与teacher encoder/normalizer开始：
- C：在原尺寸baseline继续训练；配对目标source3的采样比例与R相同。
- R：将相同目标采样槽换成这把135×16×12 mm刀的来源3有效训练初态。
- 两臂留同样比例的旧baseline来源0/1/2/3作为能力保留锚点；只改变目标组几何及对应合法初态，不同时改网络、损失、控制器、学习率、horizon或无关参数。
- 目标组可先占约75%训练槽，保留锚点约25%。确切槽位取整、状态池和标签可靠性事先登记；不按一次训练好坏临时改变配比。训练状态尽量新且多样，预算限制下用实际有效数量，不用旧最终集。
- 默认首窗口两臂各新增800次Adam更新，从实际绝对54400→55200，保存54800和55200。先测真实吞吐；如预算不足，开始前把两臂等量缩短。两臂各自checkpoint/RNG独立，optimizer连续恢复，不能将新窗口误当绝对step=800或重开teacher mixing。
- 使用原有SC-real 2076维合法输入、原latent+executed-target损失和已验证的known-controller执行记忆；来源/几何ID和runtime slider/物体真值不进入student。监督使用同一个incoming RNN，不推进真实RNN。
- 第一窗口结束就用新dev行为比较R、同更新C和父C3200。只有R出现明确但尚未稳定的持刀+开关改善、且低成本补一个窗口有望改变选择时，允许**两臂再各800更新**；否则停止。禁止反复加窗口、超参搜索和无对照单臂“磨到成功”。
- 若两臂都好，承认继续训练效应；若R仅在这把刀好却损害旧尺寸，作为有代价候选报告。训练loss不能代替行为成功。

## 4. 行为评价与停止点

主评价固定零新增阻力、外部每5秒换向、共20秒。K20联合成功=按顺序开关到误差<2 mm连续3控制点且全程有效，刀身位移<10 mm、旋转<0.25 rad。用同一rollout顺带报有序开关率、全程稳定率、首次失稳时刻和原严格S5。特别关注来源3的“旧student能动但持不稳”是否得到解决。保留一小组baseline来源0/1/2/3的零阻力保留检查，不跑原六模型×多尺寸×三协议矩阵。

从dev在R800、必要时R1600、相应C与父模型中只冻结一个主候选。用新的32个来源3有效初态作独立确认（总数32，不是每来源32），在同状态配对比较冻结候选、父C3200和同预算C；teacher仅作为必要参考。若覆盖不足报真实分母，不复制状态。确认前冻结模型、配置、评分和来源；确认后关闭数据，不为更好分数继续调参。报告各指标真实分子分母、配对四格/差值及简单区间，不把同状态的多模型当独立样本。

若确认中student能够稳定开关，再在**极少数新的诊断初态**上各试一个非零导轨阻力和上轮0.5 mm按压偏置，判断是否仍掉接触/持刀失稳。该步骤只定位下一轮“接触维持/力控制”问题，不要求本轮解决阻力、卡槽或S5。如果零阻力基础操作没有改善，就不跑这个阻力/按压附加试验。

视频取同一预登记来源3初态对比父模型、最好匹配C及主R，包含不成功部分；若三个状态表现相同，不增加视频组。视频标注和统计设备/初态差异，真实早停不假装继续操作。
