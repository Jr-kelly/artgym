# 拇指接触、推进和握持支撑：两例实际轨迹

[并排诊断图](contact-behavior-figure-v1/contact-behavior.png)来自实际下载归档、空目录恢复后运行的两条固定36秒连续轨迹：v68成功和v69高阻力失败。二者均使用冻结P50，同一桌缘摆放、同一脚本取刀和40mm命令往返。没有增加物理回合或调整控制器；不能把这两例称为可靠性统计。

| 操作期诊断（原runner的601个30Hz记录点） | v68成功 | v69失败 |
|---|---:|---:|
| 新增运行/起动幅度 | 0.2/0.2 N | 0.5/0.5 N |
| 真实求解器拇指—滑块接触比例 | 100% | 10.48% |
| 真实求解器拇指—刀身接触比例 | 0% | 91.01% |
| 记录的新增滑块关节力绝对峰值 | 0.459 N | 0.964 N |
| 拇指四关节已发目标与物理关节的最大差 | 0.142 rad | 0.166 rad |
| 记录的拇指施加力矩/原URDF effort最大比例 | 17.62% | 21.83% |
| 刀身最大转动 / 漂移 | 0.147 rad / 1.48 mm | 0.740 rad / 10.48 mm |

高阻力例在18.2秒开始持续失去滑块接触，随后主要接触刀身，23.97秒首次越过原刀身稳定判据。拇指仍会受到负载、存在关节跟踪差，也可能维持刀身接触；这些现象都不能证明仍有效压住滑块，更不能证明恒力。失接触发生在刀身稳定越界之前，提供优先检查接触位置迁移的线索，不构成因果证明。

记录的拇指力矩未在30Hz样本中触及原限幅，因此不能把此例直接归为“电机力矩上限不足”。这些力矩包括原重力补偿和有限PD，30Hz记录不是全部240Hz子步；也不能排除更快瞬态、其他支撑关节或接触力矩限制。关节差只是跟踪/负载代理，未转换成真实法向压力。

图中的滑块力是最后物理子步记录的人工被动关节力：运行耗散项加起动和槽位势能项。它不包含引擎材料摩擦、手指牵引或实物总阻力；势能下降时可正向释放储能，不能把所有正力都叫主动助推。两例同时改变了运行与起动幅度，且负载从整个取刀回合开始作用，不能孤立归因于其中一个参数或仅操作期变化。

图中接触与刀身姿态只用于评估，未输入actor。已发目标不等于恒力；接触次数不等于接触合力；每点求解器lambda也不等于实测压力。40mm是原参考往返命令，50mm是近似机械行程，都没有冒充实物已测行程。

下一阶段最值得测的是指腹接触点、实物双向起动与沿程阻力，以及能否用现有关节历史在滑块接触迁移之前识别风险。已有闭合历史155维配对原型没有改善厚刀柄支撑，尚不支持算法优势；真机力/材料标定及SDK映射仍未完成，本轮没有真机动作。
