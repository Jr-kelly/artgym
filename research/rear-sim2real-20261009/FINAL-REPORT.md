已有完整可执行入口 `scripts.run_wuji_rear`，在独立副本中从人工摆放的物理等价启动过程完成独立持刀、实测历史采集、接管、主动推动和保持。最终 v6 标称 0.7355 N 仿真主动位移 **32.42 mm**，同入口 1.25 N **28.45 mm**，两者保持约 1 秒通过。硬件没有接入，没有真机运动结果。

## 实际能运行的路径

```bash
cd /data/research/artgym-experiments-20260921/rear-sim2real-20261009
bash scripts/g2_local_python.sh -m scripts.run_wuji_rear sim \
  --output runs/my-fixed-grasp-sim --video
```

同一 `RearController` 用于 Isaac Gym 后端及隔离的 Python3.10／wujihandpy1.8 SDK 后端。支持发现设备、只读、空手小动作、人工摆刀／独立持刀、局部受载响应、5 mm 功能试推、完整闭环推动、停止与日志。现场命令、实际文件和图见 [首次真机操作](FIRST-HARDWARE-SESSION.md)。SDK 后端只下发位置，压力代理仍是模型与目标—编码器误差形成的软件位置补偿；真实 effort／切向力不可用时留空。没有把仿真 PD／重力力矩加到固件上。

推理只读取关节、FK、已发命令／动作历史、初始几何估计和固定腕方向；滑块、刀身实时位姿、接触、实际刚度／摩擦／阻力不进入控制。模型归一化沿用训练范围，设备限位独立约束发令。SDK 物理顺序、符号和零位分开处理。软件限幅／滤波后的成功发令才更新控制记忆；未经确认的原始目标单独记录。

仿真从未受载的开手姿态开始，刀由显式临时托板承托；用 3 秒合拢，撤去托板，再物理自由保持。没有恢复旧受载速度、接触缓存、50 帧历史或 RNN。实测 50 帧后隔离预热，预热不发令并恢复推理记忆，再收集 50 帧实际历史，约 6.667 秒开始推动。全部后续刀身自由运动、由手支撑，滑轨只有被动零速度制动，不驱动物体。撤去承托后无托板／地面／G2 非手部接触。沿用有限 PD、原重力、接触与 URDF 力矩限值，最终目标留 15 mrad 软件位置余量。

最终实际关节最小余量 14.4 mrad，没有模拟力矩持续饱和。v2 最初任务位移通过，但环指触及模型边界约 0.148 µrad；随后加入 15 mrad 发令余量，旧失败／诊断未覆盖。原始命令、真实已发目标、实际关节和饱和信息均保存。最终拇指接触横向最小边距约 0.35 mm，纵向约 6.92 mm；不夸大接触余量。法向 solver N、模拟电机 Nm、被动滑轨容量 N、SDK effort A 各自区分；总轴向接触力和真机法向力仍不可用。

主控制保留 v3 成功逻辑，v6 只对齐部署的预热／新历史启动流程。动态模型误差失败不因换初始化消失。现场必须先做局部受载响应和 5 mm 功能试推，失败则暂停完整推动，核对落点、执行响应和等效模型；不继续增压或泛用“再训练”。本轮已经实现、运行、比较了替代控制，未把剩余问题只写成未来待办。

`SOFTWARE-VERIFICATION.json` 验证二十关节映射、读模式拒绝写入、符号／零位转换、实际已发目标记忆和动作历史、隔离预热不发令、显式停止，以及禁止实时物体真值输入的接口。`SDK-OFFLINE-INTERFACE.json` 是实际安装 SDK 的导入／签名检查；`software/fixture-full-push-v6` 是 SDK 形状模拟对象的完整进程通信测试，不是设备连接或动力学仿真。其整段循环时延须现场重新测量；连续三个完整循环超过 33.33 ms 会停止。冻结配置还通过了 5 mm SDK 模拟对象入口：470 帧，完整循环 p95 9.43 ms／最大 14.04 ms；故意破坏一个依赖哈希时，在 SDK 连接前拒绝启动。380 帧视频指令与当前控制核心重放误差为零，属于离线一致性验证。约 0.5 秒的模型预热放在推动前保持阶段，不悄悄降低策略频率。
