Protocol scope: S2/S5 external commands follow a fixed clock. The mandated F benchmark scheduler uses true slider arrival to issue the next external command; the student receives that command, not measured slider position. F completion therefore does not establish autonomous arrival detection without a slider sensor. Runtime independence claims concern the policy given legal external commands, not an unimplemented sensor-free F command generator.
