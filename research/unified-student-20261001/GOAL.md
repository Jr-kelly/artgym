## 6. Student 方法：先排除“根本不需要复杂历史”的可能

全部方法共用固定 Eagg6100 actor/归一化器、资产、接口和输入合法性要求。

先做两个低成本参照：
C0：用训练数据计算一个全局固定 latent，整个执行过程不读取运行时特权信息。不能按来源分别存四个 latent。
C1：用实际可获得的初始信息预测 latent，执行中保持不变；小 MLP 即可。不得给来源 ID 或为每组训练不同网络。若使用仿真精确初始标定，明确条件。

它们用于判断：目前固定刀、有限初态任务是否真的需要从历史估计动态 latent。不要一开始就假定时序建模不可缺少。

主要时序路线 S0：复用仓库现有 TCN/temporal student encoder，用合法的关节与动作历史、初始信息预测统一 teacher 的 latent，再由冻结 actor 输出动作。历史长度、维度和结构从实际配置核查后登记；不要直接照搬 Sharpa 的维度或旧 Wuji 三抓姿配置。

训练监督仅来自本轮固定统一 teacher，不再混合多个原专家各自的 latent。基本损失先用已核查的 latent MSE 与原实现可选 cosine 项；记录尺度、归一化和实际梯度。冻结 actor 不等于对 latent 的梯度不可传播。

训练状态要覆盖 student 自己执行时的分布。可用有限 teacher rollout 启动，随后转纯 student rollout，在其实际状态上计算 teacher latent 标签。初始 teacher 执行/latent 混合若使用，事先登记上限与退火时点，默认不超过总训练更新的 20%；最终阶段和全部评测均为 0。

监督前保存正确时刻的输入；不要用动作后的状态监督动作前历史。只让实际行为路径推进 live actor RNN 一次；done 时正确清零，各环境历史不串流。监督支路不得改变真实执行状态。

重要：C1 如果已经通过开发和独立确认门槛，保留它作为主要候选，再做必要的历史方法对照；无需强行把 TCN 作为最终方案。若 C0 也能达标，如实说明当前任务中动态特权编码的必要性证据不足，但仍完成独立闭环验证和部署接口封装。

## 7. 给训练足量机会，再按证据分支

先做短 preflight：确认参数真的更新、actor/normalizer 不变、四来源和两种命令时长实际出现、训练与推理模式一致、存盘恢复和 RNN/history reset 正确。preflight 只验证实现，不能证明可学或不可学。

主时序路线默认登记 3,200 次真实 optimizer.step 为首个完整预算；例如在 400/800/1,600/3,200 更新时看闭环趋势。先实测“更新、rollout steps、环境交互和墙钟”的对应关系，不能把 epoch 名或脚本 updates 误当成物理交互量。

如预算足够且仍有改善，延长到 6,400 次，必要时登记 12,800 次或下一阶段；四卡增加了对照与复验的并行空间，不代表单个模型应该在 3,200 次机械停止。若实际吞吐使预算达不到目标，记录实际已完成量及“预算受限”，不要改称已经充分训练。训练恢复保留 optimizer/RNG，不能每段静默重置。

禁止因 100/200 次更新或单次来源 3 失败就宣判路线不行。判断平台至少看多个连续检查点，同时看：按来源的留出监督误差、真正执行的关节目标误差、闭环保持率/成功率和失败时间。

允许的自适应分支，按证据选择，避免同时堆模块：

A. 监督误差持续下降、闭环也改善：继续当前路线，预算优先给它。

B. teacher 轨迹上拟合好，student 自己运行后明显偏离：优先补充 student 访问状态上的 teacher 标签，检查数据回放、来源均衡和历史一致性。若改为聚合/回放训练，从同一起点保留一个等更新预算的旧数据/原训练对照。不能只和更早的弱 checkpoint 比。

C. latent 误差不大，但经过冻结 actor 后动作/关节目标误差显著：核查 latent 对动作的敏感性，再允许一条 action-aware 蒸馏分支。使用相同 incoming RNN 做反事实比较，不污染 live state；沿冻结 actor 反传只更新 student。区分原始均值、裁剪动作和最终关节目标三种误差，旧 raw-mean loss 不能冒充执行动作监督；不要直接把预测端硬裁剪后导致饱和区梯度为零。改损失要保留同起点、同预算原损失对照。

D. 发现合法输入遗漏了可由控制器准确维护的信息，例如累计关节目标或当前指令：增加这一项输入并做受控对照。真实公共状态可以用，但不能将当前刀具位姿/滑块真值包装成控制器状态。

E. 历史输入可能无法区分需要不同动作的状态：先检查有限历史、初始标定、控制器累计状态和数据覆盖。可以用诊断性 oracle latent/额外真值输入估计差距，但必须单列，不参加 student 达标。不得由一次阴性结果证明不可观测、模型容量不足或 sim2real 必然失败。

每次只增加一个主要因素。默认最多执行两条有证据触发的修复分支；不要展开大规模超参网格，也不要默认解冻 actor 或重训 teacher。若冻结 actor 路线最终不成立，交付清楚的差距和下一轮最小实验，不在剩余时间里另起大规模 RL 项目。

达到完整门槛后，优先重复最有希望路线的第二个优化随机种子；共享 teacher 和状态生成范围要明确，采集由该 seed 自己的行为产生。保留预定末点和开发选点，不只保留成功模型。

## 8. 条件成立后，补上部署与轻量鲁棒性证据

如果 student 在开发与确认集达标且预算允许：
- 封装独立推理入口：读取合法初始信息、关节/动作历史和外部目标，维护 history/RNN/控制器目标，输出与现有接口一致的动作。该入口不依赖 simulator 的当前物体真值。
- 对冻结的同一输入序列，比较训练评测路径和独立 runtime 的动作、RNN 与目标更新，使用事先登记的浮点容差；失败先修接口，不归因于 sim2real。
- 测量实际推理设备上的延迟与控制周期适配，不把 GPU batch 吞吐写成真机单实例控制频率。
- 在有条件的初始标定路线中，预登记小范围初始物体估计误差扫描，例如平移 0/2/5 mm、旋转 0/2/5°，分别改变并在同样初态上配对；这些是工程压力测试，不能声称是真实传感器误差分布。扰动估计时应在 actor 公共输入与 student 初始输入间保持一致，不改变真实初态来冒充感知噪声。

这部分优先级低于主闭环验证和第二种子。没有达标模型时不花大量时间制作部署包装或扩展鲁棒性测试。

## 9. 冻结最终评测与视频

在打开新最终集之前冻结：代码、checkpoint、输入定义、归一化、协议、候选/固定末点、同批 teacher、简单参照及排名规则。建议选点顺序：是否通过输入合法性和完整门槛 → 最差来源 S 成功 → 最差阶段保持 → 最差刀身稳定 → 更早检查点。不要按单一离线 loss 选点。

最终测试一次打开，默认 128/来源/协议。只测试预先冻结的少量必要模型，通常 teacher、主要 student、对应固定末点、简单参照和已有第二 seed，控制总成本。最终失败如实保留，不换新权重重开同一最终集。

成功/保持/存活从 pre-reset 物理轨迹计算。逐回合重算与原计数核对；记录真实 slider、goal、刀身位姿、动作、关节目标和 done 原因，不能只靠环境 success 标志。

若同批 teacher 在最终某格也未过绝对门槛，保留全部样本，分别报告 teacher 能力边界与 student 额外损失，不筛掉 teacher 失败样本提高 student 分数。最终集一旦参与诊断，即关闭，不再开发使用。

视频保持简洁：一段来源 0/1/2/3 的固定初态并排 student S2 或 S5，标明每组真实判定；一段必要的 teacher/student 同初态对照；若有失败，保留一段典型失败。初态在看结果前固定，不按最漂亮结果挑片。

视频与对应轨迹、模型哈希、硬件/批量设置一起存档；渲染重仿真与主统计运行分别报告，不用视频替代成功率。

## 10. 完成条件和 GitHub 交付
