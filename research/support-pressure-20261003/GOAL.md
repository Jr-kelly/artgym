# Codex Goal：G2 + Wuji 美工刀承托、持续按压与带阻力伸缩

## 0. 本轮目标和执行方式

接续已交付的连续仿真，不从头重做。最终服务于真机最小 demo：G2 + Wuji v1 从桌面拿起真实尺寸美工刀，稳定持握，用拇指压住滑块，完成伸出—保持—缩回。当前阶段仍先在仿真解决关键瓶颈，不自动下发真机动作，不展开折纸或切割。

本轮集中解决三个问题：
1. 无名指能否加入刀底承托，改善拇指按压时的支撑与刀身稳定？
2. 拇指是否在整个有效行程中持续压着滑块？实际法向力多少，在当前执行器和抓姿下能持续达到什么水平？
3. 同一套可部署控制/策略能否在真实尺寸附近的几何、滑块位置、接触和阻力变化下，维持承托与牵引，完成连续取刀—伸缩？

工作必须产生行为改进，不能只增加诊断和报告。力测量是选控制方案的工具；无名指承托是需要验证的候选，不预先认定五指一定优于四指；持续有效压紧是目标，不把“始终机械最大力”设成唯一实现。

自主安排至少 12 小时有价值的实施、训练与整合工作，不逐阶段等待用户。没有 GPU 小时上限或利用率指标。若主目标提前解决，按第 7 节继续必要泛化和部署准备；确实没有有价值的剩余工作才提前说明，不空转、重复评测或制造大审计凑时长。使用已授权开发机与 SSH，先核实实际可用 GPU；有 8 卡 H200 就合理使用，只有 4 卡也如实推进，不能虚报。独立训练/环境作业可并行，不启用子代理，不影响其他用户进程或 ToDesk。

最新用户目标优先于旧 Goal 中的阶段、预算和评分要求；保留历史报告和其他工作。不要为了本轮方便篡改上级权限、凭据或审批规则。实际机器无法访问时，完成本地能做的代码与离线工作，明确外部阻塞，不伪造运行。

## 3. 第一阶段：把力和失效测清楚，并立即用于改控制

优先复用现成成功、高阻力失败、厚刀柄失败轨迹，补少量必要回合。第一批就包含实际非零起动/变化阻力，不能先花几小时只调零负载端点。

### 3.1 获取可解释的实际仿真法向力

核对当前引擎接触报告的单位、时间步和 contact collection 语义。优先记录真正的拇指—滑块接触对，并按力作用方向在滑块接触面法向上投影，得到压向滑块的法向合力和沿导轨切向分量。刀身世界竖直方向和滑块局部法向不总相同，必须区分。

若 API 返回冲量，按其真实积分时间换算；若返回力，不再重复除以 dt。多个接触点只汇总一次，时间平均与空间求和区分；一个物理子步不能冒充整个控制周期。优先在 240 Hz 物理步累积并输出 30 Hz 汇总，保留少数关键时段的子步记录，不存无限全量数据。若后端只能给最后子步或不完整接触报告，明确限制，不虚构整帧压力。

用一个简单已知法向载荷/平衡场景校验数量级、符号和 dt 处理。校验夹具仅用于传感语义验证，不得用于正式 demo。必要时选后端已有接触传感方式；不能直接把手指净接触力、原始 lambda、PD 关节误差或配置里的 1.5 N 写成拇指—滑块实际压力。若短时间内无法获得可信力值，先修正确接触识别，继续承托和控制实验，同时将力数值保留为未解决，不让仪表工程拖住主线。

最少记录：拇指接触的是滑块还是刀身，拇指法向/轴向力，无名指接触刀底的反力及接触位置，刀身位姿，滑块位移，电机目标与实际关节、限幅情况。评估力来源与在线控制输入明确分开。

### 3.2 测“当前可持续压力”，不捏造硬件最大值

在已能持稳的抓姿上，选择少量递增的预压/阻抗目标，检查起点、中段和接近行程端点的可持续接触。先用当前档，再选两三个有依据的档位；只有结果影响下一步选择才加档。所有力仍由合法电机控制通过真实接触产生，不能直接给拇指或滑块施加辅助外力。

汇报有意义的压力区间、时间曲线和压力下降/丢接触位置，至少区分静止持压与边压边推。用当时姿态的关节力矩映射、限位和支撑情况解释瓶颈，不能将 URDF effort 利用率简单倍乘成指端力上限。实验找到的是“已测试条件下可持续达到的范围/下界”，不是全局最大值，更不是真机额定能力。

选择足以跨过目标阻力、又能维持接触与支撑的工作压力。摩擦近似 μN 只作为理解牵引的参考，不能保证任意型号、卡槽和姿态都可推动。若增加预压导致刀身转动、指腹移出滑块或关节到限，就转向承托/接触路径改进，不继续机械加大偏置。

## 4. 第二阶段：让无名指承托成为实际可比较的候选

保留现有四指抓姿作为基线。优先保住已经可用的桌缘取刀：尝试抬起后让无名指从可达路径进入刀底，再与其他支撑指协调承托。如果一次合理尝试表明后插入受阻，可改抓取阶段的预成形或略调手物相对位姿，不把“抬起后加入”写成不可更改的方案。

承托位置优先考虑拇指下压力附近及对刀身转动的抵抗，同时给全行程滑动留空间。关注真正的接触法向、反力和力矩；仅几何贴近、手指弯曲或碰到侧面，不算成功承托。保持无名指完整碰撞，不删除碰撞网格来获得五指接触。检查接近、加入、加压、伸出、缩回全路径，不能只检查两个端点。

只比较少数合理的承托布局，避免启动通用五指抓姿搜索平台。用同一初态、负载、动作安排和相近压紧水平比较“原四指”与“新增无名指”。首先固定其他因素看接触/稳定是否改善，再允许两套控制在相同输入和可比训练预算下各自适配，不能用未适配五指去证明无名指无效。

加入无名指有清晰收益就保留；若出现碰撞、抢占接触或刀身被顶歪，先改位置/时序/协同。如果有限的合理尝试仍没有收益，采用表现更好的支撑方案继续主线，说明具体限制。无名指参与不是最终交付的硬门槛，稳定承托才是。

## 5. 第三阶段：持续压住滑块，再克服变化阻力

优先在现有有限 PD/位置目标接口上实现最小可部署的压紧调节，例如随姿态变化的预压或阻抗目标，加关节历史驱动的有界调整。不要直接改成真机未知是否支持的力矩接口；若确有可用力矩/电流反馈，再按实际能力考虑它。明确区分“有预压”“测到持续压力”“闭环调节压力”。没有力反馈就不称精确恒力控制。

拇指滚动/推进时需要维持接触面，而非只沿固定关节轨迹增加一个恒定偏置。允许无名指及其他支撑指有界协同，必要时做小幅腕姿调整；优先最小改动，不强迫训练整条机械臂。动作改变之后同步更新已发目标和历史，避免每步累加预压造成漂移。沿用已有动作/力矩限制，补必要的饱和处理即可，不构建复杂防御系统。

可先用仿真接触真值做短诊断，验证“支撑稳 + 保持正确接触 + 足够法向力”能否解决负载；然后必须换回合法观测实现同一行为。合法关节历史不保证一定能识别所有接触状态；若估计器存在盲区，应改善抓姿和接触容忍度、考虑最少的后续传感需求，不能靠更长训练掩盖输入不足。

需要学习时，复用现有 residual RL 或必要的抓姿适配路径。先短 pilot 验证出现行为变化，再投入长训；学习的对象应包含压紧—推进—支撑协调与接触误差，不只加一个鼓励接触的奖励。训练奖励不要无限奖励大力；同时反映推进、持稳、正确接触和执行器代价。若当前滚动参考/残差幅度限制了所需动作，可有依据地改动作参数化或参考范围，不能为了保持旧 checkpoint 形式而永久困在不可用抓姿。

决策规则：
- 拇指先滑到刀身：优先接触路径、压紧和支撑，不单纯加轴向动作或延长同一训练。
- 正确接触仍在、法向力不足：改预压/姿态/执行器映射，并测实际压力响应。
- 正确接触与压力已足够但滑块不动：检查切向牵引、导轨起动/运行负载、关节限位和动作方向，避免把所有失败归为压力不足。
- 刀身先转动或滑落：优先承托与合力矩，减少只压拇指的尝试。
- 预置持刀成功，连续取刀失败：回到实际取刀末态及抓姿适配，不重置到理想状态。
- 名义刀成功、厚刀柄/滑块高度轻微变化反复失败：这是必要泛化缺口，调整可达到的接触/握持范围与训练分布，不能归为细枝末节。
- 少量误差小数、几个成功计数或 loss 改善：不足以继续同一长训。只有从丢接触到接触持续、从推不动到能推、从失稳到稳定等实质行为变化才优先追加资源。

## 6. 泛化围绕实际这把刀，训练与检查都要覆盖

沿用初始挑战范围：刀柄长 130–140 mm、宽 14–18 mm、厚 10–14 mm；滑块接触中心轴向 ±5 mm、横向 ±1 mm，凸起高度 ±1 mm。它们是仿真覆盖目标，不是用户实物制造公差。接触几何变化与滑块初始关节位置变化分别处理；初始关节状态要与刀片收起的取刀流程及目标行程相容，不因随机初始化而让任务天然无法完成。

复用已经实现的被动运行阻力、起动势阱和有界变化 profile。以当前 0.2/0.2 N 运行/起动幅度为重要参考，0.5/0.5 N 为已知困难条件；这些是模型参数，不是实物总阻力或必须达到的真实指标。按测得的能力逐步扩展，不退回只解决零负载或 0–0.10 N。没有真实推力曲线也继续有标注的仿真，不宣称已覆盖真实卡槽。若后续实测表明按压会改变导轨阻力，再加入有依据的耦合，不凭空假设按得越重总是越好。

联合训练包含尺寸、滑块接触位置、初始握持偏差、有效接触摩擦、负载 profile、初始估计误差、关节噪声/偏置及已有小延迟。使用当前引擎实际材料组合方式，不把某个单体摩擦参数当成接触对摩擦。保持质量/惯量/接触几何物理一致；episode 常量不要每帧乱跳。不要一开始无差别扩大所有随机化，先建立可工作的范围，再扩到关键条件。

同一套策略和抓姿适配机制处理整个目标族，不能按真实资产 ID 选择权重、轨迹或 oracle 抓姿。若依据有误差的初始估计规划抓姿，可以使用，但必须透明记录输入和失败。保留至少少数实际连续取刀产生的不同接触末态，不把一个固定名义抓姿加小噪声写成完整多抓姿泛化。

开发先用约 4–8 个配对条件决定方向；它们不是总评估预算上限。最终冻结候选后，用少量未用于调参的几何/组合/负载 profile 和必要重复做独立检查，包含名义、较厚刀柄、滑块高度变化和高阻力。旧 332 已知条件可用于回归，不能再次叫全新独立测试。记录取刀与操作的全部失败，不能只计算已抓稳样本。

不要求每格 32/64 回合、显著性检验、置信区间或全笛卡尔网格。只有证据不足以决定机制是否有效或是否可开始下一阶段，才补样本；不要以旧 8192 回合探索为模板再做大批复测。保留原任务行为判据，记录真实尝试数、能力边界和未测范围。

## 7. 长时间自主推进队列与收敛规则

按实际瓶颈推进，不把下面各项变成互相阻塞的审批门：
1. 复用基线并补可信接触/法向力诊断，尽早完成第一个真实控制修改和带负载 rollout。
2. 实施少数无名指/刀底承托候选，确定改善支撑的布局；把法向力档位与接触路径放在同一条件下判断。
3. 对有行为收益的压紧—推进—支撑控制进行必要训练，训练中覆盖关键联合变化。
4. 尽早接回桌面拿取—持稳—伸缩全流程，交替修取刀末态、承托过渡与操作，而非只在预置持刀场景长训。
5. 修复影响真实刀附近条件的厚度/凸起/负载失败；远端极端边界记录即可，不追微小成功率。
6. 候选稳定后做轻量独立检查、完整视频和部署接口整理。有价值的训练继续运行，不为了早点写报告杀掉有效作业。
7. 如仿真主线提前完成，整理首次真机需要的最少校准、SDK/关节映射和离线推理入口；复用已有代码，不构建全新机器人栈。外部信息缺失则标记具体缺项，继续已授权可执行工作。

不要长时间停留在“解释为什么失败”。每一轮诊断应导向可执行修改或明确停止该候选。若某机制合理尝试后反复无进展，换接触布局、动作表示或观测路线；不无限扫超参数，也不因两次失败就宣布物理不可能。

不以 12 小时内强行得出成功结论为目标。到交付时若关键问题仍未解决，保留最强可运行候选、代表性失败和最有依据的下一步，不能通过冻结物体、放松力矩、提高摩擦、筛选初态或缩短行程包装成功。

## 8. 科研目标：从真实瓶颈保留一个可验证问题

本轮优先形成可信 demo 能力。加入无名指、提高压力、普通残差 RL 或联合随机化本身都不自动构成论文创新；不重新开展文献综述，不预先命名一套复杂方法。

若实际出现稳定现象，可以检验：仅凭可部署的关节/动作历史，能否在未知阻力和握持偏差下调整接触与支撑，从而维持可操作状态？要与采用同一改进抓姿、同一随机化范围、相同可用输入及可比训练预算的普通强基线比较，不能只打赢旧名义四指 P50 就宣称算法贡献。

只在新机制已有明确收益后，再补一个能隔离关键因素的对照，例如同抓姿下的固定预压与自适应预压，或同信息下的有/无历史。没有方法优势就如实记录工程收益，继续推进真机。未来 paper 仍需要真实连续取用、未参与调参的实物/初态和与主张匹配的证据；这一轮不强制做完论文实验。

不把照片建模等同于人类视频学习，也不启动额外 HOI/retarget 流水线。长期折纸裁剪目标保留，但不分散本轮支撑与负载操作的工作。

## 9. 交付：回答能力问题，而非堆归档

在新分支与新 Release 交付实际修改的代码、最强候选权重/必要配置、可运行命令和恢复训练所需状态，保留旧 Release。复用原依赖说明，只检查新改动、必要输入映射和一次代表性启动；不要再进行全部旧文件哈希巡检、多个空目录恢复、跨 GPU 大矩阵和复杂 GPU 记账。大型旧资产引用原 Release，不重复上传。正常汇总实际训练时间/GPU 小时和主要失败作业即可。

最终中文报告首先回答：
1. 无名指是否实际接触刀底并承担反力？对持续按压/刀身稳定有无实质改善？最终为何采用该抓姿？
2. 拇指实际法向力是多少？静止与推进时分别怎样？能持续达到什么范围、哪个姿态先失效？区分优化目标、仿真测量、估计量和未测硬件能力。
3. 非零起动/变化阻力下是否连续完成桌面拿取—伸出—保持—缩回？每段由什么方法执行？
4. 真实尺寸附近哪些变化已能处理，哪些仍系统性失败？下一步是真机校准还是继续修哪个具体瓶颈？

保留一条未经阶段拼接的完整视频和少量代表性失败。尽量用全景 + 手部近景展示无名指刀底承托、拇指接触位置和完整行程；视角遮挡时增加评估叠加或补充视角，不能隐藏碰撞后假称接触。字幕显示滑块位移、法向力及其来源、接触对象、刀身稳定和当前控制阶段。将视频/关键帧直接嵌入可浏览报告，同时提供原始 MP4 链接，不只给文件清单。

力记录可信但控制未改善，不能宣称本轮任务已解决；行为改善但压力不可测，也应如实列出缺口。报告保持简短，以实际行为、关键负结果和下一步决策为主。真机未运行就明确未运行，不自动发运动命令。
