# 带阻力实验的积分修正

旧 `legacy-explicit` 用上一步速度计算 tanh 摩擦与有限导轨势阱。单看 F(v_old)·v_old≤0 不保证一个真实仿真子步的 F·Δq≤0。新记录累计每个实际子步的全部额外阻力功，加势能变化。已保存参考连续视频的旧 .2/.2 条件净残差约 +.00205 J；协调预紧在旧 .5/.5 条件达到 +1.55 J。原样保留这些开发结果，但它们不能单独证明在物理被动的相同大小阻力下具备能力，失败机制也可能被数值能量混淆。

新增 `solver-brake` 仅在物理导轨上配置原生求解器零速度制动，stiffness=0、velocity target=0、damping=250，有限制动力容量由实际导轨位置和物理负载 profile 决定。不存在滑块位置指令，不给手、刀身或滑块助推；刀身自由、原50mm导轨、G2/Wuji手臂重力与有限电机输出及原行为判据保持。起动/槽位现在是双向耗散容量，不再用保守势阱下坡助力，因此与旧载荷模型明确区分，不把两者直接当成同一实验。

`calibrate_wuji_solver_brake.py` 的固定导轨夹具只用于校验：已知外加刚体力 .75 N、容量 .50 N 给出约 -.50 N 制动力；反向同样成立，240/480 Hz 都为负功。有效质量从自由初始加速度测得约 .007 kg (.006kg滑块+.001armature)。低于容量的 .20 N 已知外力被抵抗。夹具扩展位置/速度限位仅为避免校验触碰限位，正式demo仍使用原限位。v1外力施加API错误，v2后段速度限位混淆，均保留负记录；v3校正两者。v4关节总力传感API返回0，不能用于正式场景的制动力测量。

正式scene报告的是已校验的制动**容量参数**，不能把它称为每一时刻实测摩擦、真实卡槽阻力上限或硬件力反馈。拇指滑块法向压力另由已知载荷校验过的原生接触对记录测得。所有导轨、接触、阻力真值只参与物理或评估；actor和节奏控制仍只用实际关节、已发目标/history、FK、固定初始估计和任务。

原生求解器隐式驱动与力限制原理可参考 [NVIDIA PhysX Joints](https://nvidia-omniverse.github.io/PhysX/physx/5.4.0/docs/Joints.html)；本安装封装的力单位以本轮夹具结果为准。
