# 定时评估字段的准确含义

既有 `score_timed_trace` 的 `stable_full` 同时要求完成首轮开合、600步存活/有效和全程刀身位姿稳定。因此，单看 `stable_full=0` 不能判断物体是否一直拿稳。后续明确写作“首轮完成且全程稳定”。仅持物位姿稳定应单独统计 `alive_full` 且最大平移<10mm、最大转角<0.25rad。

主要联合指标 `stable_full_all_endpoints` 要求每条固定时钟指令的最后0.3秒都在2mm以内、整段20秒位姿稳定且存活/有效，其含义和历史计数不变。它无需额外首轮条件，因为每个端点都保持已经蕴含完整开合。

functional20 CP10训练80个扰动：count1在2秒协议掉落71次、全程只存活9次，旧count掉落67次、只存活13次；两组单独计算持物位姿稳定仍均为0/80。相同初态零动作静态检查78/80稳定且0掉落。因此，策略动作后失稳的结论并非由字段命名推断。

27抓姿连续路径的脚本物理诊断中，实际执行23个训练路径，8个仅持物位姿全程稳定，3个完成首轮，2个首次严格稳定并全程稳定，1个所有指令端点保持与位姿联合成功。4个没有完整局部IK路径的训练行未执行，测试行未执行。旧 `stable_full=2` 不应解释为仅有2个物体拿稳。逐行派生结果见 `diagnostics/metric-semantics-20260922.json`；原始报告和评分程序均不修改。
