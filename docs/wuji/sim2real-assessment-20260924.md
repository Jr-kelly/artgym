# Wuji 美工刀：sim2real 差异与真实刀具建模建议

2026-09-24。用户询问当前视频对应策略的真机差异、论文措施、真实刀具精细建模是否值得。本次完成原文与本机证据核验；没有启动新的训练、真机动作或修改冻结策略。基本 teacher + student 仿真 Goal 仍为 complete，硬件是下一阶段。

## 判断

当前仿真功能成立，但不能估算真机成功率。接触、滑块阻力、执行器响应和初始化尚未实物标定；当前成功配置的物性随机化与关节观测噪声关闭。直接迁移存在明显不确定性，不能由视频流畅推断 sim2real gap 很小。

建议围绕最终使用的一把真实美工刀建立匹配的几何与力学模型，同时标定 Wuji 手。任务相关接触几何与关节阻力优先于视觉细节。不能用随机化替代完全遗漏的机构（例如必须按压解锁才能滑动），也不能靠精细外观解决执行器与接触力学误差。

## 原论文明确做了什么

来源为 ArtManip v1，在线重新读取成功（HTTP 200），原文摘录和网页 SHA256 存 `sim2real-paper-source-20260924.json`。

1. §3.2、§4.1：每类30训练几何、5未见仿真几何，程序生成模型和功能抓姿。对真实测试对象另建 primitive-based digital twin，student 仿真筛选 top-5 抓姿。人工按渲染图放置，每抓姿做5次真机试验；到位后人工切换开/关，每次40秒。
2. 附录C.5：每类试若干阻尼/刚度，分别训练 teacher，取成功仿真轨迹在一件独立真实标定物体上开环重放；保留能推动真实关节的设置，再围绕有效值选随机化范围。标定物体与测试对象分离，测试对象不再调参。“Zero-shot”没有排除事先使用标定物体。
3. 附录C.5/表8：随机化质量、接触摩擦与关节参数。Knife 刀身40–200g、滑动件10–20g、摩擦2–4、阻尼700–1300 N·s/m、刚度0；关节观测加标准差0.01噪声。作者明确这些摩擦/阻尼是仿真中的有效参数，摩擦范围适配 Sharpa 柔顺高摩擦指腹，不能当作 Wuji 的实测值原样复制。
4. §3.3、附录C.3：稳定性奖励课程逐步加强刀身稳定和接触一致性，并正则化手的运动与动作变化。
5. §3.4、附录C.4/C.6：student 从50帧本体感觉历史和已知初始化预测16维特权 latent；策略骨干冻结，student 自己驱动蒸馏采样，部署不读取当前物体特权真值。该方法缓解观测条件差异，不能自动消除动力学误差。

论文没有在上述方法段明确报告全面的执行器时延、增益、回差随机化；这些是针对 Wuji 的额外工程建议，不能归因给原文。打火机背侧贴纱布只用于 lighter，不是美工刀的统一处理。

论文全部四类300次真实执行257次至少完成一轮（85.7%），不能理解为美工刀单类成功率或40秒全程无掉落率。附录A.1指出，7个五次全部失败的抓姿中4个属于美工刀；主因是接触靠近指腹边界，阻力较大进一步放大失稳。简单方盒漏掉局部曲率和厚度变化，导致接触迁移、仿真与真实抓姿排序不一致。本体感觉策略丢失滑块接触后，不能显式重新定位滑块恢复接触。

## 当前发布模型的已核验状态

- 同一参数化刀具，整体147×19×11mm、总质量35g；刀身29g、滑块6g；实际碰撞体为两个方盒。URDF 的滑块 damping=1000 会在创建 actor 时被 `object.default_props.dof_damping=0.3` 覆盖，不能只读 URDF 推断运行参数。
- 当前运行接触摩擦3、滑块阻尼0.3、刚度0。hand/object/task randomize=false，jointNoise=0。训练有初态扰动，但这不等于物性/传感器/执行器随机化。
- Wuji 执行器参数参考了官方 MJCF；这不等于对当前实物及驱动器完成标定。ArtBot 手碰撞体来自可视网格凸包，指腹为近似接触模型，真实指腹形状与柔顺性待验证。
- student 是纯本体感觉 latent 蒸馏，已审计正式16,384,000个转移全部 student 驱动，teacher 接管0；尚无真机 SDK 闭环验证。
- 三个训练功能抓姿周围的新300初态已验证基本开合；不是物性随机化、未见物体或真机验证。20秒 student 294/300全程自然存活，60秒为240/300，持续接触稳定仍有改进空间。
- 视频高层换向读取仿真到位信号。首次真机可以复用论文的人工到位换向；若要求自动到位换向，需要真实到位观测/估计。另有固定2/5秒外部命令仿真证据，不能把仿真真值检测带到硬件。

## 真实刀具建模应投入哪里

|优先级|内容|目的|
|---|---|---|
|高|实物长宽厚、局部厚度与圆角、滑块突出高度/宽度/长度、轨道位置与行程|匹配指腹接触及拇指可达范围，避免毫米级偏差改变接触模式|
|高|双向启动推力、运动阻力随位置和速度变化、卡位与解锁动作|区分单纯黏性阻尼、静摩擦、档位阻力或额外按压自由度|
|高|Wuji 指腹实际接触形状/摩擦/柔顺性、关节零位/跟踪响应/限幅/通信延时|使握持力与推滑块动作在实机上成立|
|中|质量、质心及运动组件的质量分布；惯量给合理模型并校验|匹配重力与反作用导致的刀身运动|
|低|Logo、颜色、装饰螺丝、对接触无影响的纹理细节|当前本体感觉 student 不依赖图像外观；不值得先花精力|

CAD/扫描可作为几何来源，但碰撞网格仍宜简化、分解并检查，不应直接认为高面数更精确。刀刃/刀架可在不发生切割时先视为随滑块运动的刚体，保留必要几何和质量；本任务无需切割、断裂仿真。若真刀需要按压解锁，应显式建模或先选择与现有单滑动自由度相符的机构，并明确最终任务对象。

## 建议下一阶段次序（尚未执行）

1. 固定具体实物型号，测量几何、行程、质量及双向推力；先确认有没有卡扣/按压解锁。网络标称尺寸可作起点，不能替代这些接触与力学测量。
2. 做 Wuji 关节顺序/单位/零位、目标跟踪、力/速度限幅、30Hz策略接口和总延迟核验。仅复制官方执行器配置不足以完成这一环节。
3. 保留现有模型为基线，建立新刀具及接触模型；对冻结策略做摩擦、阻力、放置误差、噪声和延迟敏感性评估，找出最先导致失败的因素。随机化范围围绕实测及有效仿真标定，不生搬 Sharpa 参数。
4. 用实物标定结果确定有效参数；如调整物理后策略失败，从当前 teacher 尝试续训并重新蒸馏 student。现有管线、策略与数据可复用，但不能保证换真实模型后权重无需更新。
5. 以 student 在新模型上筛抓姿，优先指腹内部接触面积较大、有滑移余量的姿态；从人工放刀、单次伸出/收回开始，记录40–60秒循环和掉落。后续若声称跨物体零样本，则冻结模型并以独立实物测试；同一把刀上调参并测试只支持该刀的部署结论。
